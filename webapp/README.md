# اضافه کردن صدای واقعی صلوات

اپ آماده‌ست که یک فایل صوتی واقعی رو پخش کنه، فقط کافیه شما خودتون یک فایل mp3 انتخاب و اضافه کنید (من به‌خاطر کپی‌رایت صدای مداحان/قاریان، نمی‌تونم صدای یه شخص خاص رو بدون اجازه داخل اپ کپی کنم).

## مراحل (کمتر از ۱ دقیقه):

1. یک فایل صوتی صلوات (mp3، کوتاه، چند ثانیه‌ای) از هر منبعی که خودتون بهش اطمینان دارید دانلود کنید. چند گزینه:
   - صدای خودتون یا یکی از آشناها رو ضبط کنید (ساده‌ترین و بدون هیچ نگرانی کپی‌رایت).
   - از اپ‌های موبایل «صلوات‌شمار» که در کافه‌بازار/گوگل‌پلی هستن و صدای رایگان دارن.
   - از سایت‌هایی مثل archive.org که فایل صوتی رو با مجوز آزاد (مثلاً Public Domain یا CC) منتشر کردن.

2. اسم فایل رو دقیقاً به `salawat.mp3` تغییر بدید.

3. این فایل رو کنار بقیه فایل‌ها (`index.html`, `style.css`, `script.js`, ...) توی همون پوشه/ریپازیتوری آپلود کنید.

4. تمام! از این به بعد با لمس متن عربی صلوات، همین فایل صوتی پخش میشه — کاملا آفلاین چون فایل داخل خود اپه.

> اگه فایل `salawat.mp3` رو اضافه نکنید، اپ به‌صورت خودکار از صدای متن‌خوان (Text-to-Speech) خود گوشی استفاده می‌کنه، پس اپ همیشه کار می‌کنه، چه فایل صوتی بذارید چه نذارید.
