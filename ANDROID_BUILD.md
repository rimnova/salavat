# Android build for Salavat Shomar

The Android wrapper is a Trusted Web Activity generated by Bubblewrap.

## Required GitHub Actions secrets

`ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_PASSWORD`

See `android/README.md`.

## Outputs

The workflow generates:

- signed `app-release-bundle.aab`
- signed `app-release-signed.apk`
- `assetlinks.json`

The AAB/APK are uploaded as GitHub Actions artifacts.

## Digital Asset Links

For verified TWA, serve the generated `assetlinks.json` at:

`https://rimnova.github.io/.well-known/assetlinks.json`

A project-site path such as `/salavat/webapp/.well-known/assetlinks.json` is not equivalent because Digital Asset Links is checked at the origin root.
